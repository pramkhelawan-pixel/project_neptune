# Neptune Knowledge Standard (NKS)
## Version 1.1
### Status: Active

---

# Purpose

The Neptune Knowledge Standard (NKS) defines how every piece of knowledge enters, is maintained, and is used within the Neptune Marine Intelligence Platform.

Neptune is an evidence-based marine intelligence platform.

Every knowledge record must be:

- Researched
- Evidence classified
- Traceable
- Explainable
- Version controlled
- Continuously reviewed
- Continuously improved

---

# Neptune Principles

1. Evidence over opinion.
2. Transparency over certainty.
3. Traceability over assumption.
4. Continuous improvement over perfection.
5. User trust above all else.

# Confidence

Confidence represents Neptune's confidence in the accuracy of the knowledge.

0.00

Unknown

↓

1.00

Highest confidence

Confidence should never be guessed.

It should be derived from:

- Evidence quality
- Source reliability
- Number of independent sources
- Agreement between sources
- Review history

---

# Recommendation Weight

Recommendation Weight is NOT confidence.

Confidence answers

"How trustworthy is this knowledge?"

Recommendation Weight answers

"How much influence should this knowledge have on Neptune's recommendation engine?"

Example

Fresh Sardine

Confidence

0.95

Recommendation Weight

0.42
