## Sardine Run Tracker (KwaZulu-Natal migration event)

Track the annual Sardine Run migration event along the KZN coast.

**Scope not yet decided** — candidates:
- Informational content (seasonal timing, historical patterns, species involved)
- Crowd-sourced live sighting reports from users
- Predictive timing based on conditions data (water temp, currents, etc.)

**Gating:** Depends on subscription infrastructure not yet built.
