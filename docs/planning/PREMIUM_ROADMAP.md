# Premium Roadmap

Future premium/paid features to build after MVP launch. This is distinct from
the deferred-work/technical-debt list — everything here is net-new scope, not
cleanup.

## Sardine Run Tracker (KwaZulu-Natal migration event)

Track the annual Sardine Run migration event along the KZN coast.

**Scope not yet decided** — candidates:
- Informational content (seasonal timing, historical patterns, species involved)
- Crowd-sourced live sighting reports from users
- Predictive timing based on conditions data (water temp, currents, etc.)

**Gating:** Depends on subscription infrastructure not yet built.

## Sardine Run Knowledge Base

Educational/reference content on the Sardine Run event itself (biology, ecology,
history, hotspots along the route) — distinct from the live tracker above, which
covers timing/sightings. Could ship as static content ahead of the tracker.

## South African Fishing Spot Directory

Database of common and well-known fishing spots along the South African coastline
(location, access notes, species typically caught, spot type — rock/surf/pier/boat
etc). Scope, data sourcing (curated vs. crowd-sourced), and moderation model not
yet decided.

## Trip Cost Calculator

Calculator covering all costs for a fishing trip — fuel, bait, tackle, launch/permit
fees, etc. — to estimate trip cost up front. Scope (per-trip only vs. historical
cost tracking) not yet decided.

## Tackle Inventory

Page for users to track their own tackle (rods, reels, lures, terminal tackle) —
likely useful as a companion to the trip cost calculator and catch logging.

## Fishing Community Page

Social/community feature — scope not yet decided (feed, forums, groups, following
other anglers, etc).

## Photo Catch Upload

Attach photos to logged catches/sessions. Depends on media storage infrastructure
not yet built; may pair with the community page for sharing.
